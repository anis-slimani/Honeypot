🚀 INSTALLATION SUR LA VM - GUIDE SIMPLE
════════════════════════════════════════════════════════════════

⚠️ IMPORTANT : go.sum est maintenant exclu du transfert !
   Il sera automatiquement régénéré sur la VM.

════════════════════════════════════════════════════════════════

📦 ÉTAPE 1 : CRÉER L'ARCHIVE (sur votre PC)
────────────────────────────────────────────────────────────────

cd /home/anis/Honey
tar -czf honeypot.tar.gz internal/ templates/ config.yaml go.mod main.go install.sh check_db.sh

Note : go.sum n'est PAS inclus (c'est normal !)

════════════════════════════════════════════════════════════════

📤 ÉTAPE 2 : TRANSFÉRER SUR LA VM
────────────────────────────────────────────────────────────────

scp honeypot.tar.gz anis@192.168.1.112:/home/anis/

════════════════════════════════════════════════════════════════

📥 ÉTAPE 3 : INSTALLER SUR LA VM
────────────────────────────────────────────────────────────────

Sur la VM :

cd /home/anis
tar -xzf honeypot.tar.gz
cd Honey
bash install.sh

Le script install.sh fait automatiquement :
✓ Vérifie que Go est installé
✓ Crée les dossiers nécessaires
✓ Supprime l'ancien go.sum (si présent)
✓ Télécharge les dépendances (go mod tidy)
✓ Compile le honeypot

════════════════════════════════════════════════════════════════

🚀 ÉTAPE 4 : LANCER LE HONEYPOT
────────────────────────────────────────────────────────────────

sudo ./honeypot -config config.yaml

════════════════════════════════════════════════════════════════

✅ AVANTAGES DE CETTE MÉTHODE :

1. Plus besoin de supprimer manuellement go.sum
2. Installation automatique en 1 commande
3. Vérification des prérequis
4. Messages clairs en cas d'erreur
5. go.sum est régénéré automatiquement sur chaque machine

════════════════════════════════════════════════════════════════

🔧 POURQUOI go.sum ÉTAIT PROBLÉMATIQUE ?

go.sum contient des checksums spécifiques à :
- L'OS (Linux/Windows/Mac)
- L'architecture (amd64/arm64)
- La version de Go

En transférant go.sum de votre PC vers la VM, les checksums
ne correspondaient pas, d'où l'erreur "SECURITY ERROR".

Maintenant, chaque machine génère son propre go.sum.
